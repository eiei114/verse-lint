# V1001 — trailing-whitespace

- Default: enabled. Severity: error.
- Purpose: identify unnecessary line-end spaces/tabs without touching content.
- Policy: a tool style rule, not a Verse compiler error.
- Detect: strict lexer `Space` trivia immediately before LF/CRLF or EOF.
  Whitespace-only physical lines also count. One diagnostic spans the full run.
- Counterexamples: spaces inside strings, interpolation, characters, nested
  block comments or the end of a line comment are protected and never reported.
  Interior spacing between code tokens and normal indentation do not count.
- Safe edit planned: delete exactly the diagnosed trivia span, subject to
  reparse/token/structure validation. `--fix` is unavailable in this slice.
- Suppression: config/CLI ignore. Line directives are not implemented yet and
  explicitly fail; do not assume they suppress findings in this slice.

Bad: `A := 1` followed by two spaces before newline. Good: `A := 1` immediately
followed by newline. `# comment  ` and `A := "literal  "` are counterexamples:
their protected interior spaces remain untouched.

Tests cover LF/CRLF/BOM, EOF, blank lines, trailing tab, mixed space/tab, nested
comments/interpolation, Unicode scalar/byte positions and real Unicode paths.
