# V1003 — tab-indentation

Default on; error; **no safe fix**. Purpose: flag ambiguous indentation without
guessing how a tab changes block ownership. It aligns with space-based style,
but this implementation's exact detection policy is not a Verse specification.

Detect a tab in initial space/tab trivia on a physical code line while outside
parenthesis/bracket/brace delimiters. Report the whole indentation trivia span.
Mixed spaces/tabs count. Protected string/comment interiors, comment-only or
blank lines, and delimited continuations (including braced-body indentation)
do not count. The pinned parser must still accept the source; unsupported forms
produce execution failures rather than invented tab findings.

Bad: a tab before `Print("x")` in a spaced function body. Good: four spaces.
`"\t"`, a tab within a multiline comment and an indented array continuation
are counterexamples. Fixing other rules leaves this diagnostic in place and
exits 1. Use either line directive with a reason, or config/CLI ignore.
