# V2001 — line-too-long

Opt-in; warning; no safe fix. Purpose: an explicit team line-length policy,
not a syntax problem. Default maximum is 120; configure `max-line-length`.

Count Unicode scalars on each physical line, excluding BOM and LF/CRLF. Tabs
advance to the next four-column stop. Combining marks count individually;
emoji count as their scalar sequence, not terminal display width or UTF-16 units.
Report from the first scalar/tab exceeding the limit to the physical line end.
119/120 columns are clean at default settings; 121 is a warning.

Long URLs, comments and literals intentionally count. There is no automatic
wrap or URL exemption. Good: a line within the configured limit. Bad: a longer
line unless explicitly intentional. Suppress using either line directive with
a reason, or config/CLI ignore. `--deny-warnings` makes remaining findings exit 1.
